# BP Space — прийом коштів

Прототип кроку «Прийом коштів» картки оренди разом із блоком «Рахунки до оплати» і правим сайдбаром розрахунків. Кілька клікабельних варіантів на однакових сценах, плюс варіант 0 — порт чинного проду як антиреференс і база вимірів.

Бриф: [BRIEF.md](BRIEF.md). Візуальна система: [DESIGN.md](DESIGN.md) (копія системного файлу CRM, не переписується).

**Публічне посилання:** https://yuliiariabchuk.github.io/bp-payment-intake-prototype/

## Запуск

```bash
npm install
npm approve-scripts esbuild
npm rebuild
npm run dev
```

Відкрити http://localhost:5173/bp-payment-intake-prototype/

Прогін: `node scripts/walk.mjs` при запущеному `npm run dev`.

## Віджет «Кадри»

Лівий нижній кут. Перемикає варіант кроку, варіант сайдбару, сцену, фізособу/юрособу і роль. Стан пишеться в URL (`?v=…&rail=…&scene=…&party=…&role=…`), тож будь-який кадр відтворюється посиланням. `Ctrl+.` ховає віджет цілком.
